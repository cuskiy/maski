# Language

## Catalogs

`src/i18n/en.ts` is the source: every key, in English. `zh-CN.ts` is typed as
`Record<MessageKey, string>`, so a missing translation is a compile error rather than a
silent English sentence in a Chinese layout. `t(key, params)` looks up the current locale,
falls back to English, and substitutes `{name}` placeholders.

A sentence with a count is two catalog entries when the language needs it
(`room.joinedOne`, `room.joined`), not a plural engine. Dates, times, relative times and
file sizes go through `Intl` with the current locale.

## Locale and path

`/` is English, `/zh-CN/` is Chinese, and each is a static HTML entry with its own `lang`,
title and description. The switch sets the language, stores it, and navigates to the other
entry while keeping the hash, so a reload lands on the matching shell.

`localeFromPath` decides the first boot language; a stored choice wins over the path.

## Copy rules

- No user-facing string in a component. A literal is a defect even when it is temporary.
- No sentence built by concatenation: one key holds the whole sentence with placeholders.
- A key that no view uses is removed, so the catalog cannot drift from the interface.
- The worker never composes display text; it returns records and the view formats them.
